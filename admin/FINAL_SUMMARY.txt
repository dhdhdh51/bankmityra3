================================================================================
                              PROJECT OVERVIEW
================================================================================

Objective: Implement three separate form systems for bank recovery operations

1. BC Supervisor Visit Form (Admin Panel)
   - Supervisors inspect and assess BC Supervisors
   - GPS location capture + optional photo upload
   - Auto-populate agent details from user records
   
2. Field Visit Report (Android App)  
   - BC Supervisors visit borrowers and enter field data
   - 9 distinct report types with conditional form sections
   - Full API integration with data validation
   
3. Report Type Separation
   - CKCC OD-2 Renewal: OTS content filtered OUT
   - CKCC NPA/KRM OTS: OTS content shown
   - QR code tracking for authenticity verification
